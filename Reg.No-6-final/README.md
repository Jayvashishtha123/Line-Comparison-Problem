# Grid SW Project Portfolio - Dashboard

A comprehensive Project Portfolio Management dashboard application running on `http://127.0.0.1:5000`.

## Install

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
python app.py
```

Then open `http://127.0.0.1:5000` in your browser.
